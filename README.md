# QR Code Generator

A simple QR Code Generator built with Python.

This project allows users to enter a URL and generates a QR code for the provided link.

## Features

- Takes a URL from the user
- Generates a QR code
- Saves the QR code as an SVG file

## Technologies

- Python
- PyQRCode

## Installation

Install the required library:

pip install pyqrcode

## Usage

Run the program:

python main.py

Enter a URL when prompted:

Enter URL to generate QR code: https://github.com

The generated QR code will be saved as:

qrcode.svg
